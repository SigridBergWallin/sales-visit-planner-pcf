# Screenshots

Drop the two images below into this folder. `README.md` already embeds them, and
the first one is what a gallery listing uses as its tile image.

| File | Shows |
| --- | --- |
| `visit-plan.png` | The planned visits list alongside the map with the optimised route drawn |

## Capture guidance

- Width around 1200-1600px. Wider than tall reads better as a gallery tile.
- PNG, not JPG. Text stays legible.
- Use light theme unless the control is meant to be shown dark.
- Include the map with a route drawn. A blank map makes the control look broken.
- Show a handful of visits, not one and not fifty.

## Before you commit them

The repository ships with no customer branding, so the screenshots must not
reintroduce any. Check for:

- Customer names in account, contact, or plan records
- Customer logos or theme colours in the surrounding app chrome
- Real addresses, phone numbers, or email addresses
- The environment name and user name in the top bar

Crop the browser chrome out, or use demo records with invented names.
